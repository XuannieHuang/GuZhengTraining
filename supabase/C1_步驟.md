# C1：Google 登入 + 白名單 — 操作步驟

> 順序很重要：**① 跑 SQL → ② 設定 Google OAuth → ③ 部署新版 App → ④ 測試**。
> App 程式我會寫好；①② 是你要在後台做的部分。

---

## ① 跑 SQL（建白名單 + 改權限）

1. 打開 `D:\app\supabase\C1_google_allowlist.sql`
2. **先改最下面的「種子」區塊**：把你們**所有管理者的 Gmail**都列進去（用 Google 登入時的那個信箱）。漏掉的人會被鎖在外面。
3. 到 [SQL Editor](https://supabase.com/dashboard/project/toxfwcuhugrqwibghiig/sql/new) 貼上整段 → Run。
4. 跑完後：所有資料表的存取都改成「email 必須在白名單」。你現有的 Email/密碼登入若 email 有在白名單，仍可正常使用。

---

## ② 設定 Google OAuth（一次性、較繁瑣）

### 2a. Google Cloud Console 建立 OAuth 憑證
1. 開 https://console.cloud.google.com → 右上選/建一個專案（隨意命名，例如 classroom）
2. 左側選單 → **APIs & Services → OAuth consent screen（同意畫面）**
   - User Type 選 **External** → 建立
   - App name 填「教室管理」、User support email 選你的、Developer email 填你的 → 一路 Save
   - （測試階段可在「Test users」加入你們的 Gmail；或之後按 Publish 發布）
3. 左側 → **Credentials（憑證）→ Create Credentials → OAuth client ID**
   - Application type：**Web application**
   - **Authorized redirect URIs** 加入這一行（重要）：
     ```
     https://toxfwcuhugrqwibghiig.supabase.co/auth/v1/callback
     ```
   - 建立 → 複製 **Client ID** 和 **Client Secret**

### 2b. Supabase 啟用 Google
1. [Authentication → Providers](https://supabase.com/dashboard/project/toxfwcuhugrqwibghiig/auth/providers) → 找 **Google** → 開啟
2. 貼上剛剛的 **Client ID** 和 **Client Secret** → Save
3. **Authentication → URL Configuration**：
   - **Site URL** 設為你的 Netlify 網址：`https://stupendous-biscochitos-26954f.netlify.app`
   - **Redirect URLs** 也把上面這個網址加進去（可加 `http://localhost:5500` 方便本機測試）

---

## ③ 部署新版 App
- 把 `D:\app\prototype` 拖到 Netlify（我會先把 Google 登入按鈕、白名單把關、設定頁白名單管理寫好）。

## ④ 測試
- 打開 App → 點「用 Google 登入」→ 選你的 Gmail。
- 若 email 在白名單 → 進入 App。
- 若不在 → 顯示「尚未開通，請聯絡管理員」。
- 設定頁 →「管理者白名單」可新增/移除 email（即時生效）。

---

## 運作原理（給你理解）
- 登入用 Supabase 內建 Google OAuth（authentication）。
- 「誰能用」由 `allowed_emails` 白名單 + RLS 決定（authorization）。
- 沒在白名單的人即使 Google 登入成功，RLS 全擋、看不到任何資料。
- 白名單表本身也受保護：只有白名單內的人能讀/改它（第一筆由 SQL 種子建立）。
